Alby Hub is installed on a dedicated domain. To finish setup:

1. Open **https://__DOMAIN____PATH__** in your browser.
2. Create your wallet and **record the recovery phrase** it shows you — store it offline, outside this server.
3. Alby Hub's own UI is the only authentication layer (there is no YunoHost SSO in front).

If you restore from a YunoHost backup later, follow the verification checklist in `doc/BACKUP.md` (the wallet must be recognised, not show a "create wallet" prompt).
